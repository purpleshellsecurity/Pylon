# Pylon release assurance record (template)

- Release/version:
- Git commit:
- Build artifact/hash:
- Python version and OS:
- Model provider/model/framework version (if AI generation tested):
- Test date and operator:
- Regression suite command/result/artifact:
- Offline engine and schema version:
- Strict grading command/result/fixture inventory:
- Live workspace verification (if performed):
- Deployed rule and alert validation (if performed):
- Outstanding failures and skipped gates:
- Data/privacy review:
- AES exception (owner/rationale/expiry), if any:
- Release scope: blocked / conditional / approved
- Approver:

**Interpretation:** A check that was not executed remains *unverified*.
`approved` requires supporting evidence for the claimed scope. A successful
offline check is not proof of deployed Sentinel alert delivery.
